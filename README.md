# ERP Acadêmico (protótipo)

Protótipo de faculdade inspirado em ERPs de gestão: vendas, estoque e financeiro. Dados fictícios, guardados no navegador.
Nota fiscal simulada, sem validade fiscal.

## Como ver
- Online: importe esta pasta como projeto na Vercel (painel web, "Add New > Project"); nenhuma configuração extra.
- No computador (precisa de Node 20+): `npm install` e `npm run dev`, depois abra http://localhost:3000.
- Testes das regras: `npm run test:rules`.

O botão "Restaurar exemplo" (topo) volta os dados ao início.
